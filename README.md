# 🚀 DotNet-Playground

> A beginner-friendly repository for learning C# and .NET through theory notes, lab exercises, and practical examples.

---

## 📖 About

**DotNet-Playground** is a collection of the material I prepare and use as a **.NET Teaching Assistant (TA)**.

This repository is intended to help beginners understand .NET concepts with easy-to-follow notes, hands-on programs, and lab exercises.

As the semester progresses, more topics, examples, and projects will be added.
