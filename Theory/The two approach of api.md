## The two ways in which api has been created are  
### 1. Database first approach :
    Create database first
              ↓
    Tables already exist
              ↓
    Generate models from database
#### when to use :
  * company already has database
  * working with old systems
  * DBA team manages database
### 2. Code first approach :
    Create C# models first
              ↓
    EF Core creates database automatically
#### when to use :
  * new projects
  * rapid development
  * startup projects
  * cleaner developer workflow
